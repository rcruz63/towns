# Townsfolk (clon educativo)

Roguelite de tablero hexagonal inspirado en [Townsfolk](https://www.shortcircuitstudio.com/townsfolk), para aprender Godot 4 y diseño data-driven.

## Requisitos

- [Godot 4.6+](https://godotengine.org/download/) (**Universal**, no .NET)
- [uv](https://docs.astral.sh/uv/) (opcional, herramientas Python en la raíz)

## Arranque rápido

1. Abre en Godot la carpeta **`game/`** (contiene `project.godot`).
2. Pulsa **F5** para ejecutar la escena principal.
